# mobile-app-sk

Expo (SDK 58) app with Expo Router and TypeScript, backed by [Convex](https://convex.dev).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the Convex dev deployment. The first run logs in (or uses `CONVEX_DEPLOY_KEY`), pushes `convex/`, regenerates `convex/_generated`, and writes `EXPO_PUBLIC_CONVEX_URL` to `.env.local` (see `.env.example`).

   ```bash
   npm run convex
   ```

3. In another terminal, start the app

   ```bash
   npx expo start
   ```

## Layout

- `src/app/` — Expo Router routes; `_layout.tsx` wraps the app in `ConvexProvider`.
- `convex/` — backend functions and schema. `convex/hello.ts` is a sample query rendered on the home screen.
- `AGENTS.md`, `CLAUDE.md`, `.agents/skills`, `.claude/skills`, `convex/_generated/ai/guidelines.md` — coding-agent guidance from Expo and `npx convex ai-files install`.

## Checks

`expo-env.d.ts` (gitignored) is generated by the first `npx expo start` or `npx expo export`; `tsc` needs it for CSS module types.

```bash
npx tsc --noEmit
npx expo lint
```
